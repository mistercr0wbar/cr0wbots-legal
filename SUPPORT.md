## Operator: put the links on BARNEY’s Discord app (do this once)

This is the Discord website that owns the bot, not the BARNEY folder on
your PC, and not the crow bar.

### A. Privacy and Terms (you can do this today)

1. In a browser, go to  
   **https://discord.com/developers/applications**  
   Log in as the Discord account that **owns** BARNEY.
2. You will see a grid of apps. Click the one named **BARNEY** (the
   application, same icon as the bot).
3. The left edge is a menu. The top item is **General Information**.
   Stay on that page. (If you landed somewhere else, click
   **General Information**.)
4. Scroll down the page. You are looking for two boxes with these
   **exact labels**:
   - **PRIVACY POLICY URL**
   - **TERMS OF SERVICE URL**
5. Click in **PRIVACY POLICY URL**. Paste this, nothing else:

   `https://github.com/mistercr0wbar/cr0wbots-legal/blob/main/PRIVACY.md`

6. Click in **TERMS OF SERVICE URL**. Paste this, nothing else:

   `https://github.com/mistercr0wbar/cr0wbots-legal/blob/main/TERMS.md`

7. Scroll to the **bottom** of the page. Click the blurple button
   **Save Changes**.
8. If Discord complains the URL is invalid, you pasted a space or a
   line break. Paste again, save again.

You are done with Privacy and Terms when those two boxes still show
those two URLs after you refresh the page.

There is **no** “Support server” box on this page. That box lives
somewhere else, and it is often hidden. That is Discord, not you
missing it.

### B. Support server (only if the left menu has “Discovery”)

Discord only shows a **Support Server** field after the app is
**verified**. Most small apps are not verified. If you do **not** see
**Discovery** in the left menu, skip this whole section. The invite
https://discord.gg/qkGVG3daZS still works; people just will not see a
Portal dropdown yet.

If you **do** see **Discovery**:

1. Left menu → **Discovery**.
2. Open **Discovery Settings** (not Discovery Status).
3. Find **Support Server**.
4. It is a **dropdown of servers the bot is already in**, not a paste
   box for `discord.gg` links.
5. BARNEY must already be **a member of** the SFW support server. If
   the server does not appear, add BARNEY to that server first, then
   refresh this page.
6. Discord also wants that server to be a **Community** server:
   in Discord itself → that server → **Server Settings** → **Enable
   Community** → follow the prompts (need a rules channel and an
   updates channel).
7. Pick the SFW support server in the dropdown. Save.

Do **not** pick the personal 19+ server here.

### C. What you do not need to do

- Do not put these URLs in the crow bar.
- Do not edit the BARNEY folder on your PC for this.
- Do not enable App Directory / “Enable Discovery” unless you
  actually want BARNEY listed in Discord’s public directory. That is
  a later marketing choice. Filling Privacy + Terms does **not**
  list you.
